# Paper choice report

Use current `report --format json` for formal eligibility, scores and order. The Markdown renderer is the reproducible baseline; add a source-grounded method explanation without inventing judgments. Opening recipe: “按本轮契约与正式排序，默认先读 [formal[0]]；若优先考虑 [明确采用条件]，可先检查 [另一候选] 的 [具体部分]。” Show the official default before a different conditional reading/adoption choice. Revise and reassess if that condition is meant to change formal order. With no formal candidates, identify any qualitative reading leads and the missing comparison facts. Use “暂无可确认符合的候选” when the qualitative list is empty as well.

Actual formal order is relevance descending (R4 before R3), then comparable index descending, complete L descending, same-database OpenAlex cumulative citations descending, then stable candidate ID. A higher R3 index does not move it ahead of R4. Missing citation values are not zero. Preserve the engine's array and explain the leading relevance/fit evidence; present any different adoption preference as an explicit conditional alternative.

Keep the formal ranking visible and explain the evidence for the requested intent.

- **Framework discovery.** Describe the inputs, stages, outputs, relevant author evaluation, and scope limits. Use “经过研究评估的候选框架” for a workflow supported by verifiable author experiments on the relevant task. Show partial studies under the stages they cover. Label a workflow assembled from multiple papers “本项目候选设计，整体有待验证”, with each contribution linked to its paper.
- **Method evidence.** Lead with the specific design choice. Compare the read results in their original controls, ablations, metric definitions and datasets, including scope limits. Attach each experimental claim to the original section or result table. Explain what would have to hold for the result to transfer.

Distinguish author evaluation, independent replication, production evidence and checks pending in this project. Include a clickable original source alongside each recommendation, claim and conditional alternative. Label index-only links as discovery and identify the unavailable source. Use the candidate and evidence records to list the rest of the same-round pool once per candidate with deduplicated source links and versions.

Use the following report order.

1. One-sentence recommendation or honest absence, then contract, preferences and assumptions.
2. Formal reading-order table: paper/version links, year, task/method fit, actual venue/status/track/type, provider-specific cumulative citation counts and observation dates, official top1/top10, raw award names and landing conditions. Include L/I/V, bonus and effective weights when comparable. Follow with a condition × candidate matrix separating hard conditions from L judgments; no fabricated index for missing facts.
3. Candidate cards: first read which sections → core mechanism → evidence and limits from actually read sections → specific module to transfer to the project → reported research resources versus separately labeled project estimates → minimum validation proposal. When recommending implementation reuse, add the checked code/model/data entry points, license scope and required resources. Tie the first-choice advantage and conditional alternative to the user's environment; do not merely repeat scores. For abstracts, say “摘要级判断 / 暂定”, specify unread sections and omit experimental conclusions.
4. Deduplicated venue evidence cards, keyed by venue + edition/year + track + paper type. Each paper points to its card. Show CCF catalog version/current-catalog basis/applicability and actual source; official acceptance numerator/denominator definition; complete-cohort citation background; award setting and exact types with source completeness. If supplied official acceptance facts exist only as a short source excerpt, retain the cited observation and its explicit edition/track/type limits without deriving a rate or overwriting missing structured fields. A program page for demo/workshop can quote main-track figures; those figures do not establish that track's rate. Website identity is a separate source fact. A partial maintained mapping means partial coverage.
5. At most 2 worthwhile supplementary/qualitative leads when formal recommendations exist, and a separate pending section with missing condition/evidence. If no comparable group exists, up to 5 explicitly qualitative candidates are allowed. Show exclusions and their actual failed condition or low relevance, not a padded list.
6. Scope and sources: query time/timezone, actual per-source fetch/metric dates, run revision/snapshot, initial/deep-screen/full-text/assessed/group counts, covered and uncovered sources, failed/empty routes, API and host-search budgets/truncation, missing fields, reading depth, weights/omissions and sensitivity/closeness. An explicit scoring `as_of` and report generation timestamp are not evidence of live retrieval.

A useful minimum validation proposal names the user's target component, a small representative dataset/input, the current baseline, one method component to vary, the expected output/metric, CPU/GPU/memory/latency budget, and pass/fail observations. Separate what the paper reports, what the Agent estimates, and what a later experiment must measure. Do not install candidates or imply execution.

## Complete-cohort background

Without a verified complete official proceedings/catalog mother set, report “完整母集缺失，未计算” for venue citation percentages. Search results and the 80-paper selection pool cannot supply that denominator. Keep separately supplied cohort observations outside recommendation ranking.

For complete cohorts, preserve year/track/type/database, exclusions and source list. Show top1 H/n_h, coverage n_h/N and unknown count; show cumulative zero-citation Z/n_c, coverage n_c/N and query date. Missing citations are not zero. Show extreme missing-value bounds H/N to (H+N−n_h)/N (zero citations analogously), labeled ranges, not confidence intervals. At least 90% valid coverage permits “高覆盖观察值”, not exact completeness; 100% permits a database-scoped mother-set proportion. Lower coverage is exploratory and not used to rank venues. N=0 or valid denominator=0 is not calculable.

Default mature years are the latest three completed publication-year-plus-three-year windows, calculated at query time (2020/2021/2022 on 2026-11-17). Separate four-year-window high-citation flags from cumulative zero citations as of query. Cross-year combined values use ΣH/Σn_h and ΣZ/Σn_c, coverage Σn_h/ΣN and Σn_c/ΣN; do not average annual percentages. Every year needs a complete mother set; a year below 90% makes combined comparisons exploratory.

Award setting defaults to the last five completed editions: confirmed award editions / editions with explicit yes/no evidence, plus verified/target-five coverage. Missing pages do not mean no award. Awarded-paper proportion needs a deduplicated winner numerator and accepted-paper denominator in the same category/track scope; do not divide cross-track awards by only main-conference papers. “未核实奖项” differs from “未列入已完整核查的名单”.

Place clickable original links beside each recommendation and alternative. Use the frozen provenance.source_index for the complete candidate appendix, including eligible overflow, excluded, pending, and discovery-only entries. Preserve each link’s access status independently of the candidate’s disposition. Distinguish DOI, publisher or preprint, full text, author artifacts, and discovery pages. Link the observed experiment or section beside its result.
